CNC Pen Plotter – 3D Printed Parts
Overview
This repository contains 3D-printable mechanical parts for a CNC Pen Plotter project. The machine is designed to move a pen along the X and Y axes to draw images and simple designs on paper.

The parts are designed for 3D printing and mechanical assembly as part of an engineering project.
Project Objectives
- Design and manufacture mechanical components using 3D printing.
- Assemble the components into a functional CNC drawing machine.
- Integrate the mechanical system with electronic control components.
- Test the machine's ability to draw shapes, images, and text.
Repository Contents
This repository contains STL files for various machine components, including:
- Frame and mounting parts – Base side plates and mounting plates.
- Axis movement components – Rail brackets and belt connectors.
- Belt drive components – Pulleys and belt-related parts.
- Pen-lifting mechanism – Pen lift slider and servo mounting components.
- Electronics enclosures – Housing components for electronic parts.
File Format
The 3D models are provided in .STL format, which can be imported into compatible 3D-printing slicer software.
How to Use
1. Download the required STL files from this repository.
2. Open the files in compatible 3D-printing slicer software.
3. Check the model orientation and print settings.
4. Slice the models and export the G-code for 3D printing.
5. Assemble the printed parts with the required mechanical and electronic components.
